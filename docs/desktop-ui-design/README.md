# kcode desktop UI prototype

静态 HTML/CSS/JS 原型，用于确认桌面端的信息架构、视觉层级和交互契约。**不接 host、不接真实模型、不进入产品代码。**

## 打开

```powershell
start docs/desktop-ui-design/index.html
```

默认打开「对话」屏；底部 `PROTOTYPE` 工具条切换：

```text
对话 / 空态 / 变更 / 审批 / 计划 / 提问 / 设置 / 命令 / 引导
```

## URL 参数

| 参数 | 值 | 说明 |
|---|---|---|
| `screen` | `conversation` / `empty` / `context` / `approval` / `plan` / `question` / `settings` / `palette` / `onboarding` / `automation` / `plugins` | 直接打开某屏 |
| `theme` | `light` / `dark` | 主题 |
| `present` | `1` | 隐藏底部原型工具条，适合截图/演示 |

示例：

```text
index.html?screen=settings&theme=dark
index.html?present=1&screen=empty&theme=light
```

## 快捷键

- `Ctrl/⌘ + K`：命令面板
- `Ctrl/⌘ + B`：收起/展开侧栏
- `P`：隐藏/显示原型工具条
- `Esc`：关闭审批 / 设置 / 命令浮层
- 审批层：`1–4` 选择，`Enter` 确认

## 文件

```text
index.html    所有屏幕与组件
styles.css    设计令牌 + 布局 + 组件样式
app.js        屏幕切换、主题、命令面板、审批、composer 等交互
screens/      1440/1280 亮暗截图
```

## 已验证交互

- 空态示例 → 填入 composer → 切回对话；
- 工作区菜单、会话菜单、重命名/删除对话框；
- 附件添加/移除、权限模式、上下文容量、模型、思考强度；附件在 Composer 内横向单行排列；
- 全局字体统一：UI 14px、任务标题 14px、次级 12.5px、元信息 11px、对话正文 14.5px；
- 工具卡展开/折叠、变更文件选择、打开编辑器；
- 侧栏顶部小型产品标识 + 产品名 + 本地徽标；无前进/后退、不可切换；
- 任务列表：项目分组 + 嵌套任务 + 未归类任务；项目不显示计数；项目/任务组可折叠；点击项目或“任务”标题自动展开；项目标题右侧 `+` 添加项目；hover 项目行 `+` 新建任务；任务标题右侧 `+` 新建未归类任务；固定行高，切换不跳动；
- 添加项目（打开本地文件夹）、项目/任务归档与删除、信任一次后新任务不再询问；
- 新建任务进入当前项目；点击“任务”标题或没有项目时进入未归类任务；
- 一级导航：对话 / 自动化 / 插件市场；
- 自动化模板、临时任务、定时任务对话框；
- 插件市场来源切换、安装、插件管理；
- 全页设置、左侧分组导航、模型/外观/权限/快捷键/使用统计/归档；
- 模型设置页内添加供应商、供应商详情、套餐额度、模型开关；
- 子智能体 / MCP / 命令 / 钩子表单，MCP/技能导入；
- 插件添加、技能新建直接进入会话；
- 底部终端、右侧“新标签页”面板、帮助菜单；
- Provider 添加、测试连接、保存、更换 key；
- 插件启用/停用/移除/安装；
- `Ctrl+K` 命令面板、输入过滤、键盘选择；
- 审批四档、计划批准/调整/放弃、提问选项；
- Onboarding 预设、保存、稍后配置；
- 侧栏折叠、context 抽屉、`present=1` 截图模式。
